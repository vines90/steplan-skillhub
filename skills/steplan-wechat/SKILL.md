# Steplan 公众号排版

文章内容 → `article.json`（模板 + 块列表）→ 脚本渲染出 `index.html`（预览 + 一键复制）。样式全部由脚本保证，Claude 只负责把内容映射到合适的块。

## 流程

1. **拿到文章**。用户没给就请他粘贴或给文件路径。Word 先转成文本再读。
2. **选模板**（用户指定了就用指定的）：

   | template | 名称 | 适合 |
   |---|---|---|
   | sop | 实战干货 | 教程、SOP、工具用法、步骤清晰的干货 |
   | essay | 深度观点 | 观点、行业观察、品牌故事、创始人随笔（深色整篇） |
   | case | 案例战报 | 客户案例、学员成果、项目复盘、有前后数据的 |
   | weekly | 阶梯周刊 | 多条资讯 / 工具合集、周报 |
   | camp | 招募发布 | 训练营招生、活动报名、产品发布 |

3. **写 article.json**。先读 `references/blocks.md`（字段、骨架、长度限制），再复制 `assets/examples/` 里同模板的范例改内容。默认存到当前目录的 `公众号文章/YYYYMMDD-短标题/article.json`。
4. **渲染**：

   ```bash
   python3 ~/.claude/skills/steplan-wechat/scripts/steplan_wechat.py render 公众号文章/…/article.json --shots
   ```

   输出到 json 所在目录：`index.html` + `预览图/01-*.png`。出现 ⚠ 提示必须处理掉。
5. **看截图验收**。长图按 2000px 切片查看，重点找：标题只剩一两个字落单、卡片里文字挤、三栏/两栏塞不下。用 `\n` 调断行、缩短文字或换块，再渲染。
6. **交付**：告诉用户 index.html 路径、粘贴方法、需要替换的东西（虚线图片位、占位价格等），提醒用手机预览并开深色模式检查。

## 内容规则

- **不改写文章**：保留全部事实、顺序、观点和结论。只做排版层面的调整：拆长段、把并列内容转成列表 / 卡片、挑一两句做金句。
- **不编造**：数据、价格、引语、客户名只用文章里有的。块需要的数据文章里没有，就不用这个块；必须占位时写明显的占位（如 `X,XXX`），并告诉用户。
- **克制强调**：`==绿色块==` 每节最多一两处；`keypoint` 金句卡全文最多 1 张；不要每段都加粗。
- **品牌固定项**：
  - 尾卡由脚本自动追加（slogan、三横杠、已上线产品 sohobot.cc / s1.steplan.io、关注引导），不要在正文里重复写。
  - **任何地方都不放二维码**。转化用「后台回复关键词」或「阅读原文」。
  - 公众号正文的外链点不了，网址写成纯文本，越短越好。
  - 酸性绿只做色块，或用在深色底上；不要用绿色文字压在白底上。

## 扩展组件

现有块不够用时，在 `scripts/steplan_wechat.py` 里新增组件函数，再用 `@block` 注册（函数名 `b_类型名`，第一个参数是主题 `t`）。必须遵守：

- 只用行内 style；不用 class、id、position、SVG、CSS 变量、gap、`<style>`。
- 装饰性的点和横杠用 `shape()` / `dot()`（块级 section + `<br>`，防止编辑器删空标签）。
- `<p>` 里不能嵌 `<section>` 等块级元素；颜色从主题 `t` 取，深浅两种主题都要能看。
- 加完后渲染一次，⚠ 检查会报出上面这些问题。

## 模板总览页

阶梯计划项目里的 `公众号排版模板/` 是 5 套范例的总览页，用下面的命令重新生成：

```bash
python3 ~/.claude/skills/steplan-wechat/scripts/steplan_wechat.py render ~/.claude/skills/steplan-wechat/assets/examples/*.json -o 公众号排版模板 --shots
```
