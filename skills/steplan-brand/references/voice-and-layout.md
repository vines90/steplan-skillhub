# 品牌文案与版式规则

## 名称与写法

- 中文「阶梯计划」，英文「Steplan」（句中首字母大写）；标志里的文字是小写「steplan」；等宽标签里写「STEPLAN」。
- 中英一个品牌，不拆「中文站 / 英文站」等子品牌。
- 官网 **steplan.ai**。

## 主张

- slogan：「只带最核心的，去最远的地方。」/ Send only what matters.
- 品牌关键词：极致效率 · 想象力 · 决心
- 业务：外贸 + AI 外贸培训。我们是「一支用 AI 重做外贸的团队」。

## 文案风格

- 短、准、具体：先说对方得到什么，再说怎么做到。少用「赋能、颠覆、极致体验」这类空话。
- 数字要真实；示例数据必须标「示例」，或用 X,XXX 之类的占位。
- 标题一句话讲一件事；金句用「只带最核心的……」这种克制的口吻，不喊口号。

## 版式规则（来自用户反馈）

- **标题区极简**：顶部只放标题。不要叠「品牌页眉 + 英文 / 中文双语小标签 + 标题」三层。
- **品牌位置**：页脚左「● STEPLAN 阶梯计划」，页脚右「steplan.ai」（PPT 可在网址后跟页码）。
- **内容区要大**：装饰性的标签层不加分；一页 / 一屏只讲一件事。
- **二维码**：公众号文章里不放二维码（尾卡只留关注引导，转化用「后台回复关键词」）；海报、课程宣传可以放报名二维码。
- **清晰度**：屏幕物料按 2 倍分辨率出图。

## 各类物料

| 物料 | 做法 |
|---|---|
| 公众号文章 | 技能 steplan-wechat（5 套模板） |
| 海报、封面图 | 技能 steplan-poster（课程、活动、产品、金句、封面） |
| PPT | `assets/templates/Steplan-PPT模板.pptx`，先装 `assets/fonts` 里的字体 |
| 网页 | 引入 `assets/tokens.css`；做网站时凭品牌理解设计，不套用前端设计类技能的通用风格 |
| 头像 | `logo/png/steplan-app-icon@2x.png`，或 `scripts/logo.py` 导出 mark |
| 名片 | 深空黑正面 + 骨白背面，参考 VI 展示板「名片」格 |
