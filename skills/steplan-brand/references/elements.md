# 图形元素

所有元素都来自标志本身：圆点 = 大脑，三横杠 = 阶梯，前倾 = 跃迁。只在有意义的地方用，不要堆砌。

## 1. 圆点（大脑）

- 实心圆。浅底用深空黑，深底用酸性绿，绿底用深空黑。
- 用法：
  - 标签前缀「● STEPLAN 阶梯计划」
  - 大号圆点放在版面一角（VI「品牌主张」格）
  - 阶梯 / 路线图最高处「飞出」的那一点
- 一个版面通常只有一个「主圆点」。

```html
<span style="display:inline-block;width:.5em;height:.5em;border-radius:50%;background:#C8FF2E"></span>
```

## 2. 三横杠

- **VI 应用元素版**：三条横杠左对齐，长度短 / 中 / 满（30% / 58% / 100%），前两条深空黑（深底用骨白），最后一条酸性绿。用作结尾标记、分隔、页脚装饰。
- **进度版（阶梯指示）**：三条横杠右对齐，上短下长，从下往上点亮 n 级，表示「第 n 阶 / 共 3 阶」、难度、评分。亮的用深空黑（深底用酸性绿），没亮的用 #DCDDD6（深底 #3A3C44）。

## 3. 阶梯（逐级升高）

三张卡片顶边逐级升高、底边对齐，最后一级用深色或酸性绿点亮，最高处可放一个「飞出」的圆点。用于三步流程、课程三阶、价格三档、路线图。项目多于 3 个时改用列表，不要硬做 5 级台阶。

## 4. 阶段胶囊

全圆角胶囊，三种状态：

| 状态 | 样式 |
|---|---|
| 已完成 | 实心（浅底：深空黑底 + 白字 + 绿点「●」；深底：酸性绿底 + 深空黑字） |
| 进行中 | 描边 1.5px，字同描边色 |
| 规划中 | 虚线描边，石墨灰字 |

文字格式：「第 1 阶 · 已完成」。

## 5. 高亮色块

- 酸性绿底 + 深空黑字，或深空黑底 + 酸性绿字（反白）。
- 用在标题里最想强调的一个短语上，左右留 0.1em。一个版面一两处。

## 6. 点阵插图

- 半调点阵组成的圆球沿一条弧线逐级变小、变亮，尾迹之后飞出一团酸性绿圆点（「只送大脑」）。背景散布灰色小点组。
- 现成素材：`assets/texture/texture-tall.png`、`texture-wide.png`（透明底），适合放深色底右侧或角落，可以出血裁切。
- 不要用写实照片、3D 渲染、霓虹光效代替它。

## 7. 等宽小标签

英文全大写 + 中文，用 JetBrains Mono，字距 0.12–0.16em，石墨灰。格式「KICKER · 中文」，如「CURRICULUM · 课程大纲」「No.018」。标题区只放一层，不叠在标题上方再加一层。

## 8. 卡片与圆角

扁平、无阴影。浅底上用白卡片，深底上用 #1F2027 卡片。圆角随尺寸：PPT 约 0.12in，海报 18–24px，公众号 6–8px。
