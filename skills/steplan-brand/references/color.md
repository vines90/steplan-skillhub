## 搭配规则

- **三种底色情境**：
  - 浅色（骨白底、深空黑字）
  - 深色（深空黑底、白 / 骨白字）
  - 酸性绿（绿底、深空黑字，用于金句、强调页、主视觉）
- **酸性绿只做强调**：色块、圆点、横杠、深底上的数字和标签。浅底上**不用绿色文字**（对比度不够）。要在浅底上强调，用「酸性绿色块 + 深空黑字」或「深空黑色块 + 酸性绿字」。
- **比例**：一套物料整体按 46 / 28 / 14 / 12。单页可以整版酸性绿（VI 展示板「品牌主张」格就是），但一套里最多一两页。
- **高亮写法**：
  - 浅底、深底：酸性绿底 + 深空黑字
  - 酸性绿底：深空黑底 + 酸性绿字（「反白」）
- **不要**：电光紫 #5B2EFF（用户明确不喜欢）、其他彩色、渐变彩色、大面积纯黑 #000 或纯白文字压在绿色上。

设计变量见 `assets/tokens.css`（CSS 变量 `--st-*`）和 `assets/tokens.json`。
